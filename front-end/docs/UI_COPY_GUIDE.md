# Scenara 多语言界面文案规范

Scenara 提供中文和 English 两种互斥的界面模式，默认使用中文。用户选择保存在浏览器中，并在后续访问时自动恢复；同一界面不会同时显示两种语言。

## 使用原则

1. 阶段名称、功能模块、状态和关键动作必须同时维护中英文文案，但只展示当前语言。
2. 英文文案按实际产品语义编写，不逐字翻译中文句子。
3. 英文使用简洁的行业术语，不使用装饰性或含义重复的词组。
4. 同一概念在侧栏、页面标题、任务队列和导出页中保持一致。
5. 切换语言不改变页面结构、业务数据和生成内容语言。

## 核心阶段术语

| 中文 | 英文 | 使用场景 |
| --- | --- | --- |
| 剧本策划 | Story Planning | 故事输入、剧本生成与分镜规划 |
| 视觉设定 | Visual Development | 角色定妆、场景和道具资产 |
| 镜头设计 | Shot Design | 关键帧、视频、对白与镜头质检 |
| 剪辑交付 | Delivery | 预览、母版、素材和工程交付 |
| 提示词库 | Prompt Library | 提示词检索、编辑和版本管理 |

## 组件约定

页面和功能标题优先使用 `BilingualLabel`，组件只渲染当前选择的语言，由 `mode` 控制展示形式：

- `stacked`：侧栏、页面主标题。
- `badge`：阶段工作台标题。
- `inline`：卡片标题、工具栏和紧凑状态。

表单字段和长段帮助文本无需全部双语化；只有当英文能帮助跨团队沟通或明确专业概念时才添加。
